\subsubsection{3.2 研究内容}

本项目围绕海杂波场景电磁频谱数据智能处理机理与方法展开研究，针对海杂波场景下目标信号微弱、连续宽频段数据规模大、边缘节点算力链路受限等问题，构建“频谱信号提取—数据轻量存储—高效智能处理—原型系统验证”的完整理论与方法体系。首先，\textbf{研究海杂波干扰下微弱电磁频谱信号传播规律与提取方法}，提升弱目标频谱特征的可观测性、可分辨性和可提取性；其次，\textbf{研究有限算力端侧频谱数据轻量存储与可信管理方法}，支撑高价值频谱事件筛选、压缩存储、快速检索与可信追溯；接着，\textbf{研究基于频谱知识图谱的轻量化目标识别与可信协同决策方法}，实现频谱知识演化、弱目标识别、轨迹研判与多节点可信协同决策；最后，\textbf{开展海杂波场景电磁频谱数据智能处理原型系统验证}，推动关键技术落地，提升复杂海洋环境下电磁频谱的自主感知、轻量管理与智能决策能力（整体框架如图\ref{fig:research_content}所示）。

\textbf{研究内容一：海杂波干扰下微弱电磁频谱信号传播规律分析与提取}

面向复杂海洋环境中无人目标频谱信号能量弱、持续短、边界不稳和特征分散的问题，本项目拟研究海杂波干扰下微弱电磁频谱信号传播规律分析与提取方法。针对海况、传播通道与目标可观测性耦合关系不清的问题，研究\textbf{复杂海洋环境下电磁频谱信号时空耦合规律建模}，形成支撑弱信号提取的场景先验和传播参数。针对强海杂波、同频干扰和多径残余遮蔽目标特征的问题，研究\textbf{基于干扰对消的微弱目标频谱特征增强方法}，提高目标谱线、调制边带和短时轨迹的可分辨性。针对弱目标信号边界模糊、成分混叠和参数难获取的问题，研究\textbf{基于多维联合表征的电磁频谱信号精确提取方法}，实现候选区域定位、邻近成分分离和关键参数反演。

\textbf{研究内容二：有限算力端侧频谱数据的可信管理和轻量存储方法}

面向海警船端连续宽频段监测中频谱数据规模大、有效事件稀疏、端侧算力存储受限与可信管理开销高的问题，本项目拟研究有限算力端侧频谱数据的可信管理和轻量存储方法。针对连续频谱流难以高效组织和全量精判代价高的问题，研究\textbf{事件窗口驱动的频谱数据价值评估模型}，实现高价值可疑事件筛选、AI 识别触发与向量入库控制。针对海量频谱表征向量存储成本高、磁盘检索 I/O 开销大和持续写入维护困难的问题，研究\textbf{基于表征压缩的频谱向量数据库存储优化方法}，支撑频谱表征向量的轻量存储、高效检索和动态维护。针对频谱证据防篡改、可信查询和全流程追溯需求，研究\textbf{链上链下协同的可追溯频谱数据可信管理方法}，实现高价值频谱证据的可信存证、快速定位与可验证追溯。

\textbf{研究内容三：基于频谱知识图谱的轻量化目标识别与可信协同决策方法}

面向海杂波干扰下海域自主侦测中态势动态变化、边缘资源受限与多节点可信协同不足的问题，本项目拟研究资源受限边缘场景下的频谱即时认知与自主决策方法。针对离散频谱事件难以有效组织和支撑任务推理的问题，研究\textbf{态势驱动的频谱知识图谱构建与动态演化方法}，形成服务态势理解与目标关联的知识表示。针对低算力、低时延条件下弱目标识别不稳和态势研判滞后的问题，研究\textbf{知识驱动的轻量化频谱目标识别与轨迹分析方法}，提升目标识别、未知类型发现与轨迹预测能力。针对多边缘节点认知冲突、可信差异和链路受限问题，研究\textbf{基于有限链路轻量安全传输与低延时确权的分布式可信协同决策方法}，支撑多节点融合研判、协同确权和决策留证。

% \textbf{研究内容四：海杂波场景电磁频谱数据智能处理原型系统验证}

% 本项目拟开展海杂波场景电磁频谱数据智能处理原型系统验证，面向异常无人艇、无人监测浮标、无人海面漂移平台、无人作业船艇等典型海域无人目标，集成海杂波场景电磁频谱信号传播建模、强海杂波干扰下微弱信号提取、有限算力端侧频谱数据存储和边缘频谱数据即时智能处理等方法。研究重点不在单一模块功能演示，而在构建从场景构设、频谱采集、传播表征、干扰抑制、弱信号提取、端侧存储、边缘判别到岸基复核的原型验证链路，检验所提方法在复杂海况、强海杂波、复杂电磁干扰和受限算力条件下的有效性、稳定性和可复现性。

% （1）海杂波场景电磁频谱数据智能处理原型实现。围绕典型海域无人目标电磁感知侦测需求，构建海上接收平台、软件无线电采集单元、端侧频谱处理节点、边缘智能分析节点、频谱数据底座和岸基复核平台协同运行的原型系统。研究内容包括典型无人目标辐射信号、海况气象条件、海杂波背景和电磁干扰因素的统一组织，形成目标真值可标定、场景参数可调节、频谱数据可采集的验证条件；建立频谱数据、环境参数、平台状态、算法结果和复核结论之间的关联机制，贯通原始观测、事件触发、特征提取、数据存储、边缘判别和岸基复核过程。通过原型系统集成，实现海杂波场景电磁频谱数据智能处理方法从单点算法验证向系统链路验证的转化。

% （2）面向方法有效性的验证指标与闭环评估。围绕传播规律建模、微弱信号提取、端侧频谱数据存储和边缘即时智能处理四类核心方法，建立可量化、可对比、可复核的验证指标体系。针对传播规律建模，重点评估传播参数估计误差、接收强度预测误差、频谱特征漂移和可观测性边界偏差；针对微弱信号提取，重点评估杂波抑制比、信杂比改善、检测概率、虚警率、漏警率、参数估计误差和特征保持程度；针对端侧存储，重点评估关键证据保持率、压缩比、存储占用、检索时延、索引命中率和追溯完整性；针对边缘处理，重点评估目标识别准确率、未知目标发现能力、决策时延、通信开销和多节点研判一致性。通过真值标定、对比试验、岸基复核和指标回传，形成场景复现、效能评估、问题定位、模型校准、知识更新和再验证的闭环评估机制。

% （3）典型海域无人目标应用场景验证。围绕近岸巡查、远海观测和漂移平台监测三类用例开展场景化验证。近岸巡查面向无人作业船艇、异常无人艇等目标，重点研究活动突发、距离较近、岸岛遮挡、多径明显、民用通信和同频干扰密集条件下的微弱辐射事件触发、干扰抑制、弱信号增强和目标活动证据保存能力。远海观测面向远距离异常无人艇、无人海面漂移平台等目标，重点研究目标距离远、辐射功率低、海况变化快、观测链路受限和平台运动影响显著条件下的传播规律表征、信号可观测性分析、边缘即时判别和结果回传能力。漂移平台监测面向无人监测浮标、无人海面漂移平台等长期布设或随流漂移目标，重点研究辐射信号间歇、能量较弱、位置变化缓慢和证据链不连续条件下的多维特征提取、端侧价值评估、语义压缩存储、快速检索和多节点一致性研判能力。通过上述应用场景验证，形成覆盖典型海域无人目标发现、证据保存、边缘判别和岸基复核的原型验证体系。
\textbf{研究内容四：海杂波场景电磁频谱数据智能处理原型系统验证}

面向异常无人艇、无人监测浮标、无人海面漂移平台和无人作业船艇等典型海域无人目标，本项目拟开展海杂波场景电磁频谱数据智能处理原型系统验证。针对单点算法难以反映系统链路效能的问题，\textbf{构建海杂波场景电磁频谱数据智能处理原型系统}，贯通频谱采集、传播表征、弱信号提取、端侧存储、边缘判别和岸基复核流程，形成可运行的原型验证链路。针对方法效果难以量化对比和复核的问题，\textbf{建立面向方法有效性的验证指标与闭环评估机制}，覆盖传播建模、信号提取、轻量存储和即时处理等核心环节，支撑效能评估、问题定位和模型校准。针对不同海域用例下目标特性和干扰条件差异显著的问题，\textbf{开展典型海域无人目标应用场景验证}，检验所提方法在近岸巡查、远海观测和漂移平台监测中的有效性、稳定性和可复现性。
