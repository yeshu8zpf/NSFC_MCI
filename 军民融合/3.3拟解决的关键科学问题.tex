\subsubsection{3.3 拟解决的关键科学问题}

本项目围绕海杂波场景电磁频谱数据智能处理，按“信号—数据—认知”主线，凝练出从强杂波下微弱信号精准提取、有限算力端侧轻量可信存储到多平台可信协同认知的三个相互递进的关键科学问题。

% 问题一
\textbf{科学问题一：海杂波干扰下微弱电磁频谱信号的传播机理表征与精准提取问题（“看得清”）}

在复杂海洋环境与高密度电磁对抗背景下，如何从非平稳强杂波中高保真地捕获侦测目标的微弱辐射信号，本质上是一个带物理传播规律约束与小样本约束的弱信号精准提取问题。一方面，海杂波呈现显著的非高斯、非平稳与多径时空耦合特性，与微弱瞬态目标信号深度交叠，使基于统计平稳性假设的恒虚警检测与空时自适应处理普遍面临检测门限失效、杂波对消残余严重的根本矛盾；另一方面，侦测目标信号往往具有低信噪比、高动态与短时猝发特征，且可用先验样本稀缺，叠加平台运动与信道时变带来的特征漂移，单纯依赖数据驱动模型难以稳健刻画其时频结构。因此，如何揭示海杂波环境下电磁频谱信号的时空耦合传播机理，构建涵盖“传播规律建模”“杂波对消增强”与“小样本特征学习”的精准提取框架，在强干扰抑制与微弱特征保真之间求取动态平衡，实现从复杂背景中“看得清”微弱辐射源，是本项目亟需解决的首要关键科学问题。

% 问题二
\textbf{科学问题二：有限算力端侧频谱数据的价值感知与轻量可信存储问题（“存得下”）}

在海域广域自主侦测任务中，如何在端侧有限存储与算力约束下实现海量高维频谱数据的关键价值感知与可信留存，本质上是一个带多重资源约束的频谱数据协同优化问题。一方面，边缘感知节点持续产生的海量高维频谱数据与受限的存储、算力资源之间存在根本矛盾，现有固定阈值或均匀采样的端侧存储策略缺乏对数据时空关联价值与事件重要性的细粒度评估能力，易导致关键异常被循环覆盖或因压缩产生语义失真；另一方面，在无人值守的高对抗分布式环境下，传统中心化管理难以抵御恶意篡改，无法满足执法取证对数据完整性与可溯源性的刚性要求，而全量上链又会带来端侧难以承受的存储与共识开销。因此，如何建立价值驱动的自适应分级压缩机制，并融合链上链下协同的可信存储方法，在受限算力存储与证据完备可信之间求取动态平衡，确保关键证据“存得下”且“证得真”，是本项目面临的第二个关键科学问题。

% 问题三
\textbf{科学问题三：面向海域自主侦测任务的多源频谱认知智能高效处理与分布式可信协同问题（“判得快”）}

在海域自主侦测任务中，如何在时延与能耗约束下实现多源频谱的高效认知处理与多节点可信协同，本质上是一个带算力—时延约束与信任约束的分布式认知优化问题。一方面，边缘节点面临海杂波动态变化、辐射源类型多样与通信链路间歇中断等多重挑战，单站观测存在盲区且虚警率高，而传统深度学习模型受制于端侧算力与功耗，难以兼顾多类微弱信号的高精度识别与实时响应；另一方面，多站协同受限于有限带宽与节点互不信任，现有融合方法多依赖全量数据传输或集中式云端决策，既不适应海上弱连接信道，也难以抵御被俘节点注入的虚假信息。因此，如何构建面向海域自主侦测的智能高效处理架构，以混合专家模型等轻量化技术实现按海况与辐射源类型的自适应路由与稀疏激活推理，并借助区块链保障协同过程可审计与决策结果可信抗抵赖，在低资源消耗与高精度、高可信判决之间求取动态最优，真正做到“判得快”，是突破广域海域可靠自主侦测的核心科学问题。
